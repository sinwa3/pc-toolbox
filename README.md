# 컴퓨터용 프로그램

개인 PC(Windows 11)에서 쓰는 작은 편의 도구 모음입니다. 도구마다 폴더 안 `README.md`에 자세한 사용법이 있어요.

## 브라우저 유저스크립트

[Tampermonkey](https://www.tampermonkey.net/)가 설치된 브라우저에서 **설치** 버튼을 누르면 설치 화면이 열립니다. 설치한 뒤에는 자동으로 업데이트됩니다.

### 🕒 SOOP 다시보기 댓글 타임라인 · `soop-timeline`

숲 다시보기의 댓글·답글에서 타임라인(시간 + 소제목)만 모아 플레이어 옆 패널에 보여 줍니다. 항목을 누르면 그 시간으로 이동합니다.

[![설치](https://img.shields.io/badge/-%EC%84%A4%EC%B9%98-00485B?style=for-the-badge)](https://raw.githubusercontent.com/sinwa3/pc-toolbox/main/tools/soop-timeline/soop-timeline.user.js) &nbsp; [사용법](tools/soop-timeline/README.md)

### 📌 다시보기 책갈피 (숲·치지직) · `vod-bookmark`

숲·치지직 다시보기에서 지금 시간을 메모와 함께 책갈피로 남기고(영상당 5개), 어느 화면에서든 책갈피한 영상 목록을 열어 그 시간으로 바로 갑니다.

[![설치](https://img.shields.io/badge/-%EC%84%A4%EC%B9%98-00485B?style=for-the-badge)](https://raw.githubusercontent.com/sinwa3/pc-toolbox/main/tools/vod-bookmark/vod-bookmark.user.js) &nbsp; [사용법](tools/vod-bookmark/README.md)
