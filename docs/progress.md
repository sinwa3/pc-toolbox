## 설계 결정

- `.sh` 훅은 `.gitattributes`로 LF 고정. 이 PC는 `core.autocrlf=true`라서 CRLF로 체크아웃되면 bash 훅이 실행되지 않는다.
- 돋보기: Windows 기본 돋보기 사용(확대/축소 간격 5%, Ctrl+Alt+휠). 사용자가 써 보고 충분하다고 판단. ZoomIt은 휠 한 칸에 2배씩 바뀌어 "연속 확대" 요구에 안 맞고, Virtual Magnifying Glass 등은 2019년 이후 유지보수 중단. 부족해지면 C# + Magnification API(소수 배율 지원)로 직접 만드는 안이 있다.
- 비공개 도구: GitHub는 저장소 단위로만 공개/비공개를 정할 수 있어서 `private/` 폴더 안에 별도 비공개 저장소를 둔다. 상위 저장소는 `.gitignore`로 `private/`를 제외한다. 저장소 전체를 비공개로 바꾸면 유저스크립트 raw 설치·자동 업데이트가 깨져서 택하지 않았다. 비공개 유저스크립트는 자동 업데이트 없이 직접 붙여 넣어 설치한다.
- 브라우저 유저스크립트(Tampermonkey)도 이 프로젝트의 `tools/<이름>/`에 둔다. 스크립트가 많아지면 별도 저장소 분리를 다시 검토한다.
- GitHub 저장소는 public. 유저스크립트를 raw 링크로 설치하고 `@updateURL`로 자동 업데이트하려면 공개여야 한다(비공개 raw 링크는 토큰이 필요해 Tampermonkey가 못 받는다). 그래서 개인정보·토큰은 커밋하지 않는다.
- soop-timeline: 기존 후보 중 왁타임라인(크롬 확장, 약 3,000명)은 Firefox 미지원, "SOOP 타임라인 활성기"(유저스크립트)는 화면에 불러온 댓글만 읽고 라이선스가 비공개라 고쳐 쓸 수 없어서 직접 만들었다.
- soop-timeline: 댓글은 화면의 "더보기"를 누르지 않고 숲 댓글 API로 직접 받는다(빠르고 화면 구조 변화에 덜 민감). 여러 사람의 타임라인은 작성자별로 묶고(타임스탬프 3개 이상), 1~2개짜리는 "한 줄 댓글", 그리고 "전체 합치기"를 따로 둔다. 기본 보기는 가장 많은 작성자.
- soop-timeline: 긴 다시보기는 여러 파일로 나뉘어 `video.currentTime`이 안 맞으므로, 숲의 `a.time_link[data-time]` 위임 클릭 처리를 빌려 시간 이동한다.
- vod-bookmark: 기존 후보 중 "치지직 나중에 보기(북마크)"(크롬 확장)는 영상 단위 저장만 되고 시간대 책갈피가 없으며 치지직·크롬 전용. 숲용 책갈피 도구는 못 찾음. 그래서 직접 만든다.
- vod-bookmark: 스크립트 하나로 숲과 치지직을 같이 지원한다. Tampermonkey 저장소는 스크립트별이라 하나여야 두 사이트 책갈피가 한 목록에 모인다.
- vod-bookmark: 저장은 `GM_setValue`(확장 저장소, 사실상 무제한). 영상 1,000개 ≈ 0.5MB라 용량 걱정 없음. 브라우저 간 공유는 안 되므로 필요해지면 JSON 내보내기/가져오기를 붙인다.
- vod-bookmark: 영상당 책갈피 최대 5개(시간 + 메모). 가득 차면 추가를 막고 알린다(오래된 것 자동 삭제 안 함).
- vod-bookmark: 화면 — 다시보기 화면에 책갈피 추가·목록·클릭 이동·삭제. 두 사이트 모든 화면에 떠 있는 "책갈피 영상" 버튼 → 영상 목록(최근 순, 숲/치지직 표시) → 영상을 펼치면 책갈피 목록. 영상 제목 클릭 = 그냥 열기(아래 참고), 책갈피 클릭 = 그 시간으로 열기.
- vod-bookmark: 다른 영상으로 갈 때는 주소에 `#bm=<초>`를 붙여 열고 영상 페이지의 스크립트가 읽어 이동한다(사이트별 시간 파라미터에 기대지 않음). 숲 긴 다시보기는 soop-timeline의 `a.time_link` 방식 재사용.

- vod-bookmark: 치지직 조사 결과 — 본 영상 `video.webplayer-internal-video`는 파일 하나라 `currentTime`으로 바로 이동(사용자 확인). 영상 정보는 `api.chzzk.naver.com/service/v2/videos/<번호>`. 다른 영상으로 갈 때 페이지를 새로 열지 않으므로(SPA) 0.5초마다 `location.href`를 비교한다(`history.pushState` 가로채기는 Tampermonkey 격리 환경에서 복잡해 안 씀).
- vod-bookmark: 치지직은 Claude의 내장 브라우저와 Claude in Chrome 둘 다 안전 제한으로 막힌다(숲은 내장 브라우저로 열린다). 치지직 화면 조사는 사용자가 콘솔에 조사 스크립트를 붙여 실행하고 결과를 전달하는 방식으로 했다. 숲 시험은 내장 브라우저 콘솔에 GM 함수 대체(localStorage) + 스크립트 본문을 넣어 했다(로컬 서버에서 불러오기는 막힘).
- vod-bookmark: 숲도 다음 영상 자동 재생 시 페이지를 새로 열지 않고 주소만 바뀐다. 주소 감시가 두 사이트 모두에 필요하다.
- vod-bookmark: 스타일은 `#vbm-panel`/`#vbm-list` 아래로 범위를 좁힌다. 숲 CSS가 플레이어 안 버튼 배경을 덮어써서 생긴 문제(v0.1.1에서 수정).
- vod-bookmark: 목록에서 제목 클릭은 시간 지정 없이 연다. 사이트의 이어보기 위치가 있으면 그리로 간다(사용자 결정).
- vod-bookmark: 왼쪽 아래 목록 버튼은 넓은 화면·전체화면에서 재생바의 일시정지 버튼과 겹쳐 누를 수 없었다(다시보기·실시간 모두). 화면 종류로 나누지 않고, 버튼 자리에 `<video>`가 깔려 있으면 숨긴다(0.5초마다·크기 변경·스크롤 시 확인). 숨었을 때 다시보기에서는 패널의 `☰`로 목록을 열고, 실시간 방송에서는 넓은 화면을 끄면 다시 보인다.
- vod-bookmark: 패널은 플레이어 왼쪽 위(soop-timeline 패널이 오른쪽이라 겹치지 않게), 단축키 `B`, 목록 버튼은 화면 왼쪽 아래 고정.
